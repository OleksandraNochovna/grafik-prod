Grafik dnia - wersja v4

Jak używać:
1. Rozpakuj ZIP.
2. Otwórz plik index.html w przeglądarce albo wrzuć go do GitHub Pages.
3. Dane zapisują się lokalnie w przeglądarce.
4. Przycisk DANE służy do eksportu/importu JSON między urządzeniami.

Zmiany v4:
- checkboxy są w odcieniach szarego,
- produktywność jest zawsze widoczna; gdy nie ma wpisu, pokazuje poziom 3,
- po prawej stronie wykresu są skale dla pozostałych parametrów,
- sen zapisuje się tylko raz na dany dzień i kolejny zapis nadpisuje poprzedni,
- zmienione emoji produktywności i przycisków,
- naprawiony błąd JavaScript, przez który przyciski mogły nie otwierać okna.
